# Design

## Context

The core layout and documentation-publishing spec currently designate pkg.go.dev. Active verify-public-delivery artifacts have already been reconciled to local API inspection and source-license acceptance. Use package comments and executable examples as source, with commands such as `go doc github.com/jani123/dome/core/resource` in the selected workspace. Align the remaining maintained release documentation with that delivery change, retaining its ownership of actual public tagged-module retrieval, source/license notices and executable-example acceptance. Do not claim that choosing local docs prevents public indexing. This does not request any remote hiding action.

## Risks / Trade-offs

These are proposed changes, not completed implementation or acceptance. Preserve unrelated work and historical evidence; update current guidance without rewriting archived history.
