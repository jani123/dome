---
title: Dome guides
---

Dome is a Go library for compiling your own infrastructure agent. Define resources
and playbooks in Go, load values from typed YAML, and use SOPS for secrets.
A coding agent can help author the project; the compiled agent runs without AI.

These are development guides until a release is published. Use the guides and API
matching your project's pinned Dome version. Start with the quickstart, then read
resource authoring and recovery before adding privileged host operations.
