# Decisions

- [Configuration sources](typed-config-and-secrets.md) - Go defines topology while typed YAML and SOPS supply values without persisting secrets.
- [Project initialization](version-pinned-starter.md) - One release binds generated source, dependency, skill, and template metadata.
- [Consumer authoring](ai-for-authoring-only.md) - Coding agents assist Go authoring while deployed agents remain independent of AI.
- [Customer source access](customer-independence.md) - GPLv3 source access supports customers changing their agents and service providers.
- [Maintainer artifact boundaries](maintainer-artifacts.md) - Structured specs and curated knowledge replace committed ad hoc plans.
